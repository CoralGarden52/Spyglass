## Constraints and review focus

- Never execute a mutable Skill instead of its frozen version. Tenant/user/run identity comes from verified server context and every query is scoped.
- Product/pricing/sentiment calls overlap; global semaphore, individual timeout and wall-clock Run deadline include waiting, and cancellation propagates.
- Unknown usage stays null; audit contains version/hash/times/model, not secrets/private text/hidden reasoning. Checkpoints contain references, not webpages.
- Search snippets are explicitly labelled. Quotes/comments must be literal excerpts of actual evidence. Mixed counts once; per-aspect denominators are separate.
- Missing/foreign evidence, malformed outputs, contradictory/outdated claims trigger real Collector/Analyst/Writer routes; bounded repair ends needs_review with actual before/after hashes.
- DNS rebinding/private IP/redirects/robots/response sizes are enforced in web_fetch; retrieved text is untrusted data, never higher-priority instructions.
- Public execution/SSE and full report/trace centres are subsequent slices; basic read APIs/UI are the minimal current vertical readback.
