# 定价策略分析

版本：0.1.0 · 协议：schema_version 1

## 目标与范围

对照真实套餐价格、币种、计费单位、限制和适用人群，保留采集时间。

## 方法

1. 优先采集官方价格页与计费条款，记录币种、月付或年付、按席位或按量计费及采集时间。
2. 区分免费额度、促销、税费、地区差异与企业询价；未知报价为空，不编造估算。
3. 整理套餐限制和商业化策略，为商业模式与 SWOT 提供可查询事实；有金额时必须有币种和计费单位。

## 来源与权限约束

- 所有事实结论保留可查询 Evidence ID 和来源定位；没有来源时明确 insufficient_evidence，不用缺失等同于不支持。
- 仅使用后端授予的工具和上下文；本 Skill 不读取环境变量、密钥或本地用户文件，不执行源码，不突破工具白名单。
- 按指定输入输出 Schema 交接。正文不得把测试 fixture、置信度、截图数字或推断当作真实业务数据。

## 输出交接

输入 `EvidenceInput`，输出 `PricingResult`；配置由 `AnalysisConfig` 验证。保留版本、证据引用、缺失项和采样限制。场景上下文不替代四项必选分析；分析结果不得在未执行时伪装成已完成。
