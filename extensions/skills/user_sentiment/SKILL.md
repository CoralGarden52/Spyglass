# 用户评价分析

版本：0.1.0 · 协议：schema_version 1

## 目标与范围

抽取真实评论的整体四分类和方面级情感，报告去重样本、分母与来源偏差。

## 方法

1. 每条评论先分 positive、negative、neutral、mixed 四类，再提取方面和 opinion_span；同一 mixed 评论可在性能方面正向、价格方面负向。
2. 按指纹及来源去重。整体分母是去重评论数，一条 mixed 评论只计一次；方面级分母是该方面已分类观点数，不能与评论级分母混用。
3. 保留平台、Evidence ID、采集或原发布时间（未知为空）、语言与引用许可；不得合成真实用户样本或任意抓取私有材料。
4. 输出真实样本数、四分类比例、方面统计、痛点和亮点、可追溯代表样本及来源偏差。置信度仅为分类不确定性，不代表评论真实。
5. 没有样本时明确 insufficient_evidence，不生成占比；样本不足警告与采样范围一并进入 SWOT 和报告。

## 来源与权限约束

- 所有事实结论保留可查询 Evidence ID 和来源定位；没有来源时明确 insufficient_evidence，不用缺失等同于不支持。
- 仅使用后端授予的工具和上下文；本 Skill 不读取环境变量、密钥或本地用户文件，不执行源码，不突破工具白名单。
- 按指定输入输出 Schema 交接。正文不得把测试 fixture、置信度、截图数字或推断当作真实业务数据。

## 输出交接

输入 `EvidenceInput`，输出 `SentimentResult`；配置由 `SentimentConfig` 验证。保留版本、证据引用、缺失项和采样限制。场景上下文不替代四项必选分析；分析结果不得在未执行时伪装成已完成。
