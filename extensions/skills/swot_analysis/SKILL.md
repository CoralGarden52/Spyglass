# SWOT 分析

版本：0.1.0 · 协议：schema_version 1

## 目标与范围

综合产品、定价和评价产物，形成带证据的优势、劣势、机会和威胁。

## 方法

1. 先读取三项基础分析引用及其有效状态，不把上游证据不足改写成确定事实。
2. 优势与劣势从有来源的产品、定价和用户观点提炼；机会与威胁还需外部市场或环境证据。
3. 每一判断保留 Evidence ID，说明支持或反驳关系；矛盾来源不强行合并，缺失项明确证据不足。

## 来源与权限约束

- 所有事实结论保留可查询 Evidence ID 和来源定位；没有来源时明确 insufficient_evidence，不用缺失等同于不支持。
- 仅使用后端授予的工具和上下文；本 Skill 不读取环境变量、密钥或本地用户文件，不执行源码，不突破工具白名单。
- 按指定输入输出 Schema 交接。正文不得把测试 fixture、置信度、截图数字或推断当作真实业务数据。

## 输出交接

输入 `DependentAnalysisInput`，输出 `SWOTResult`；配置由 `AnalysisConfig` 验证。保留版本、证据引用、缺失项和采样限制。场景上下文不替代四项必选分析；分析结果不得在未执行时伪装成已完成。
