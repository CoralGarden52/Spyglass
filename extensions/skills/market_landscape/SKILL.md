# 市场格局分析

版本：0.1.0 · 协议：schema_version 1

## 目标与范围

基于可核验来源整理参与者、定位、竞争梯队与差异，不虚构市场份额。

## 方法

1. 明确行业范围、地域和时间，识别公开资料可支持的参与者与定位。
2. 竞争梯队必须解释判定口径；没有口径一致的份额或规模来源时不生成份额百分比。
3. 趋势需要至少两个真实可比采样时点；否则只做现状分析，保留缺失和偏差。

## 来源与权限约束

- 所有事实结论保留可查询 Evidence ID 和来源定位；没有来源时明确 insufficient_evidence，不用缺失等同于不支持。
- 仅使用后端授予的工具和上下文；本 Skill 不读取环境变量、密钥或本地用户文件，不执行源码，不突破工具白名单。
- 按指定输入输出 Schema 交接。正文不得把测试 fixture、置信度、截图数字或推断当作真实业务数据。

## 输出交接

输入 `EvidenceInput`，输出 `MarketResult`；配置由 `AnalysisConfig` 验证。保留版本、证据引用、缺失项和采样限制。场景上下文不替代四项必选分析；分析结果不得在未执行时伪装成已完成。
