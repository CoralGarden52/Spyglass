# 战略建议分析

版本：0.1.0 · 协议：schema_version 1

## 目标与范围

整合四项基础分析，形成有依据、可行动且标注风险的战略建议。

## 方法

1. 先核对四项核心产物和 SWOT 的支持状态，再确定机会和风险优先级。
2. 每项建议连接可查询的证据与前提，说明目标用户、适用条件、风险和验证方式。
3. 区分事实和建议，不能把建议包装成已发生的结果；未验证的方向标注假设并提出最小验证行动。

## 来源与权限约束

- 所有事实结论保留可查询 Evidence ID 和来源定位；没有来源时明确 insufficient_evidence，不用缺失等同于不支持。
- 仅使用后端授予的工具和上下文；本 Skill 不读取环境变量、密钥或本地用户文件，不执行源码，不突破工具白名单。
- 按指定输入输出 Schema 交接。正文不得把测试 fixture、置信度、截图数字或推断当作真实业务数据。

## 输出交接

输入 `DependentAnalysisInput`，输出 `StrategyResult`；配置由 `AnalysisConfig` 验证。保留版本、证据引用、缺失项和采样限制。场景上下文不替代四项必选分析；分析结果不得在未执行时伪装成已完成。
