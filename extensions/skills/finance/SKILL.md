# 金融行业

版本：0.1.1 · 协议：schema_version 1

## 目标与范围

比较金融服务、收费、风控、隐私、合规与客户信任的公开信息。

## 方法

1. 先限定司法辖区、目标客户和产品类型；合规状态必须注明监管主体、文件日期与适用范围。
2. 对照费率、账户限制、风险揭示和隐私条款，不能把公开宣传当作监管批准。
3. 评价应区分服务体验与投资结果，不能从个别收益评价形成投资建议或伪造回报承诺。

## 来源与权限约束

- 所有事实结论保留可查询 Evidence ID 和来源定位；没有来源时明确 insufficient_evidence，不用缺失等同于不支持。
- 仅使用后端授予的工具和上下文；本 Skill 不读取环境变量、密钥或本地用户文件，不执行源码，不突破工具白名单。
- 按指定输入输出 Schema 交接。正文不得把测试 fixture、置信度、截图数字或推断当作真实业务数据。

## 输出交接

输入 `ScenarioInput`，输出 `ScenarioContext`；配置由 `ScenarioConfig` 验证。保留版本、证据引用、缺失项和采样限制。场景上下文不替代四项必选分析；分析结果不得在未执行时伪装成已完成。
