# 商业模式分析

版本：0.1.0 · 协议：schema_version 1

## 目标与范围

结合产品与定价证据分析收入、成本、渠道及变现方式。

## 方法

1. 以已验证套餐、渠道说明和公开披露梳理收入路径，区分公开事实与推断。
2. 成本结构只使用公开材料；不虚构毛利、收入或客户数量，资料不足时明确未知。
3. 比较定价单位、获客与交付路径，为建议产物提供带证据的机会与限制。

## 来源与权限约束

- 所有事实结论保留可查询 Evidence ID 和来源定位；没有来源时明确 insufficient_evidence，不用缺失等同于不支持。
- 仅使用后端授予的工具和上下文；本 Skill 不读取环境变量、密钥或本地用户文件，不执行源码，不突破工具白名单。
- 按指定输入输出 Schema 交接。正文不得把测试 fixture、置信度、截图数字或推断当作真实业务数据。

## 输出交接

输入 `DependentAnalysisInput`，输出 `BusinessResult`；配置由 `AnalysisConfig` 验证。保留版本、证据引用、缺失项和采样限制。场景上下文不替代四项必选分析；分析结果不得在未执行时伪装成已完成。
