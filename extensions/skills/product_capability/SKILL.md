# 产品能力分析

版本：0.1.0 · 协议：schema_version 1

## 目标与范围

建立基于证据的产品定位、功能树与功能对照，区分能力深度和支持状态。

## 方法

1. 统一功能名称与对照粒度，将官网、文档和可核验体验映射到功能树。
2. 功能状态使用已支持、部分支持、未发现来源、明确不支持、待验证五种，不把搜索不到当成不支持。
3. 每项功能差异记录 Evidence ID 和适用版本，缺证据的定位或能力标为部分支持或证据不足。

## 来源与权限约束

- 所有事实结论保留可查询 Evidence ID 和来源定位；没有来源时明确 insufficient_evidence，不用缺失等同于不支持。
- 仅使用后端授予的工具和上下文；本 Skill 不读取环境变量、密钥或本地用户文件，不执行源码，不突破工具白名单。
- 按指定输入输出 Schema 交接。正文不得把测试 fixture、置信度、截图数字或推断当作真实业务数据。

## 输出交接

输入 `EvidenceInput`，输出 `ProductResult`；配置由 `AnalysisConfig` 验证。保留版本、证据引用、缺失项和采样限制。场景上下文不替代四项必选分析；分析结果不得在未执行时伪装成已完成。
